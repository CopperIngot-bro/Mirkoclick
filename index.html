How did we get here?

The beginning of Mirkoclick was not like you would expect. first of all it was not intended to be a clicker at all.

it was supposed to be a web page where I taught my friend how to do HTML. That's why it is named my first page in Serbian.

He quit the HTML so I took the page for myself. I did not do anything intended for it to be my project this is big or something, it was just like a joke.

I started adding some JavaScript and CSS and slowly but surely I started to make this page bigger and bigger.

It was not a small thing anymore, but it became my main project. So I needed to give it a name. I called it wc wc wc wc wc olja.

If you wonder why it has name like that, it's from a meme in our friend group.

In Serbian WC means closet and WC šolja means toilet.

I made a joke wc wc wc wc... šolja. That was like supermega giga toilet or something like that.

I tried to name my website like that but it just didn't let me use the 'š' symbol in URL.

A few days ago my friend asked me to rename wc olja to something Mirko themed, so it's easier to access by searching the web. I didn't want to change the URL of my project because it's iconic. I thought a long time about it and decided to create a website that is named Mirkoclick that has wc olja's biography and the direct link to the website.
